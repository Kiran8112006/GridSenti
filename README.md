# GridSenti

AI-Assisted Detection & Localization of Invisible High-Impedance Downed Conductors

---

## Problem

A downed electrical conductor can sometimes remain energized because a high-impedance fault (HIF) may produce a relatively small or unusual fault current that conventional overcurrent protection may fail to recognize. This creates severe public safety risks — the conductor is invisible to the protection system yet deadly to anyone who approaches it.

---

## Planned Solution

GridSenti aims to use:

- Distributed monitoring nodes (ESP8266 / future edge nodes)
- Electrical telemetry (current, voltage, waveform analysis)
- Signal processing & feature extraction
- Rule-based detection engine
- AI/ML anomaly classification
- Fault localization algorithms
- Utility operations alerts
- Public safety warnings

---

## Current Prototype

The current prototype has:

- **Next.js** frontend dashboard
- **FastAPI** backend (Python)
- **ESP8266** edge-node simulation

> ⚠️ **IMPORTANT:** There are currently **NO physical electrical sensors**.
> All electrical telemetry generated by the ESP8266 is **simulated**.
> The ESP8266 is being used to demonstrate the future edge-node communication architecture.
> No high-voltage electrical connection is used.

---

## Planned Architecture

### Real future system:

```
Electrical Sensors (CT/PT/Rogowski coil)
  → ESP / Edge Node
  → GridSenti Backend
  → Signal Processing & Feature Extraction
  → Rule Engine + AI/ML
  → HIF Detection
  → Fault Localization
  → Utility Alert
  → Isolation Recommendation
```

### Current prototype:

```
ESP8266
  → Simulated Telemetry (HTTP/MQTT)
  → GridSenti Backend (FastAPI)
  → Dashboard (Next.js)
```

## ⚠️ Safety Notice

This project concerns electrical infrastructure concepts.

**NEVER connect any prototype hardware directly to:**
- Mains electricity (120V / 230V)
- 11 kV, 22 kV, 33 kV distribution lines
- Any dangerous or high-voltage source

The current prototype operates entirely on **simulated telemetry only**.
